# The Architecture Lab

The Architecture Lab is my public learning journey into software architecture, distributed systems, AI systems, scalability, cloud infrastructure, and modern engineering practices.

The goal is not just to learn technologies, but to understand why they exist, what problems they solve, and how they work together in real-world systems.

Through a series of experiments, projects, architecture diagrams, benchmarks, and technical write-ups, I will explore topics such as:

- Distributed Systems
- System Design
- Networking
- Databases
- Caching
- Message Queues
- AI Engineering
- RAG Systems
- AI Agents
- Cloud Infrastructure
- Docker & Kubernetes
- Observability
- Performance & Scalability

This repository serves as a living lab where every project is an experiment and every experiment is an opportunity to understand systems at a deeper level.
